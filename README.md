1. PROJECT OVERVIEW
----------------------------------------------------------------------
This project is an experimental analysis of hardware behavior under 
different stress conditions. There is no software application to "run". 
Instead, this repository contains data logs, screenshots, and graphical 
analysis of a test machine (HP EliteBook 840 G5).

----------------------------------------------------------------------
2. HOW TO INSPECT THIS PROJECT (For Instructor)
----------------------------------------------------------------------
Please follow these folders in order to verify the project:

* 01_specs: Contains screenshots of the test machine specifications.
* 02_logs_raw: Contains raw CSV data logs generated by HWiNFO64.
* 03_logs_cleaned: Contains processed/cleaned Excel data.
* 04_graphs: Contains the final visualizations (Temperature & Usage 
  trends for CPU, RAM, GPU, Storage, and Mixed workload).
* 05_screenshots: Contains visual evidence (Task Manager, Stress Tools).
* 06_reports: Contains the Final Report (PDF/Word) and Experiment Log.
* 07_tools: Contains a list of tools used.
* 08_diagram: Contains the System Architecture Diagram.

----------------------------------------------------------------------
3. TOOLS AND AI DISCLOSURE
----------------------------------------------------------------------
Tools Used:
- HWiNFO64 (Hardware Monitoring and CSV Data Logging)
- Prime95 (CPU and RAM Stress Testing)
- CrystalDiskMark (NVMe SSD Benchmarking)
- WebGL Aquarium (Browser-based GPU Stress Testing)
- MS Excel (Data Cleaning and Graph Generation)

AI Assistance:
- ChatGPT was used for troubleshooting tool configurations, 
  understanding thermal concepts, and structuring the report.

4. REQUIRED SOFTWARE TO VIEW FILES

- Microsoft Excel (to open CSV logs)
- Any Image Viewer (for .png screenshots and graphs)
